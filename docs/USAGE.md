# 使用指南

## 配对与设备管理

在运行 Gateway 的电脑上执行 `npm run pair -- --open`，手机扫码后点击“连接电脑”。二维码五分钟内一次有效。正常刷新和重新打开网页会保留配对；需要解除时可从手机退出，或在电脑管理设备：

```bash
npm run devices
node --import ./scripts/env.mjs --import tsx src/server/cli.ts revoke <device-id>
```

撤销会阻止该设备继续发起请求。已签发的对象存储链接仍可能有效到到期时间。

## 会话与项目

“最近”按更新时间显示会话，“项目”按桌面项目归属分组。可展开项目、搜索标题或项目名称，并加载更早的会话与历史消息。

已在桌面加载的会话可以直接控制。没有桌面 owner 的会话先提供只读历史；可尝试“在电脑打开此会话”，等待桌面加载后再发送。新建入口使用桌面原生能力，可创建独立会话或选择现有本机项目。

## 发送、追加、中断与排队

空闲时输入消息并点击箭头发送。任务运行时，点击发送会把文字追加到当前任务；长按 650ms 会排到下一轮，松开不会再发送一次。移开手指可取消长按，键盘等价操作为 Alt+Enter。

运行时清空输入，发送按钮会变为暂停图标，点击后中断当前 turn。暂停图标对应中断操作，不是可原地恢复的挂起。

右上角菜单可查看、移除排队消息和查看操作记录。运行中追加/排队暂不支持附带文件、技能和插件，选中这些内容时需等当前任务结束后发送。

## 模型、计划、技能与插件

点击模型名称，在同一个面板选择模型、推理强度与速度，再点击“应用到下一轮”。运行中的任务保留原设置。

“工具”菜单提供计划模式开关。启用后输入区显示“计划”标签，点击标签上的关闭按钮可恢复默认执行方式。

技能和插件面板支持搜索与多选，点击“添加到消息”后才应用选择；关闭面板会取消本次未确认的改动。选中的内容与本条草稿绑定，发送成功后清除，不会自动沿用到所有后续消息。

## 问题与审批

点击问题卡片上的“回答”，逐题选择或输入内容。可以返回修改，最后核对并提交全部回答；仅选择选项不会自动提交。收起面板会保留本页答案，刷新页面不承诺保留答题草稿。

命令和文件审批会展示相关命令、路径或 Diff。按卡片提供的选项允许或拒绝。尚未适配的交互需要回到桌面处理。

## 附件与富内容

输入框的加号用于选择图片和文件。文件上传完成后仍需点击发送；手机上传保留原始内容，当前最多十个附件、单文件上限 256 MiB。

普通消息中的图片直接显示，工具查看的图片位于对应活动折叠内。音视频使用浏览器播放器，可播放、暂停和拖动进度；编码支持取决于浏览器。代码、公式和图表会在内容稳定后完成排版。

文件链接只允许访问已经在当前会话中发送的附件。文件已被移动或删除时，旧链接可能失效。

## 断线与更新

断线期间可以阅读已加载内容，控制在恢复同步后重新启用。手机关闭或断开不会停止桌面任务。

“结果待确认”表示请求可能已送达，但尚未得到确定结果；先查看桌面记录，不要直接重发。

网页有新版时会提示刷新。未提交文字、附件、答案或正在提交的操作会阻止意外刷新；完成或清空后再更新。
