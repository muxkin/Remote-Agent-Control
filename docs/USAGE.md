# 使用指南

## 页面入口

在“消息 / 联系人 / 工作台 / 我的”之间切换：PC 导航常驻左侧；手机仅在一级页面显示底部导航，进入对话或管理详情后隐藏，返回时恢复。工作台继续处理 Codex 项目与任务；消息模块支持真实账户、单聊和群聊；在联系人页生成一次性邀请，即可让 Dot 等支持 HTTP 的 Agent 注册接入。注册会分配永久字符串 UID，登录与添加联系人支持 UID 或 @用户名。“我的”提供账户资料、设备与设置。

“我的 → 设置 → 清理缓存”是唯一显示缓存用量的位置。清理不解除配对，也不删除草稿和未确认操作。应用不限制持久化缓存大小，不提供预算设置或自动淘汰。

## 工作台实例外观

点击工作台卡片右侧的设置按钮可修改实例名称、说明和图标。图标支持内置图形、单个 Emoji、PNG/JPEG/WebP 图片（最大 5 MB，自动裁切压缩为不超过 192 px 的 WebP）。保存后同一主机的已配对设备自动同步；“恢复默认”会清除覆盖值，重新使用接入插件的默认显示。更名不改变实例 ID、会话或连接设置。

工具可以在主机仓库中使用同一份配置：

```bash
npm run instance -- list
npm run instance -- show codex-local
npm run instance -- set codex-local --name '编程助手' --description '桌面协作' --image /path/icon.png
npm run instance -- set codex-local --emoji '🦄'
npm run instance -- reset codex-local
```

CLI 默认读取 `local/gateway.env`，可用 `POCKET_ENV_FILE` 指向运行主机的环境文件。设置保存在主机状态数据库，重启、升级接入插件后仍保留。只设置命令中指定的字段，空说明用 `--description ''`；需要防止覆盖其他编辑时传 `--revision <show 返回的版本>`。修改后工作台最多约 10 秒同步。

已配对客户端的加密 RPC 提供 `backends.appearance.read` 和 `backends.appearance.update`，对应 `GET/POST /api/backends/:id/appearance` 的内部路由映射（不是云端公开 HTTP 接口）。更新正文为 `{ "revision": 0, "patch": { "name": "编程助手", "description": "桌面协作", "icon": { "kind": "emoji", "value": "🦄" } } }`。图标还可为 `builtin`（`code/terminal/puzzle/chat/monitor/book/folder/sun`）或 `image`（小型 PNG/JPEG/WebP data URL）。字段设为 `null` 恢复该字段默认值。过期版本返回 409，未知实例返回 404；连接状态、能力、插件类型不接受外观接口修改。

窄输入栏（含手机与窄桌面聊天面板）只显示权限、工具图标，点击后可查看完整设置；宽屏保留按钮文字。模型名称优先保留空间，发送和停止按钮保持独立。

发送进度仅显示在按钮内，确认收到后清空草稿。附件上传完成后只保留附件卡片，不显示完成横条。结果未知时保留草稿，用“核对状态”查询原请求，不重复提交。只有明确未发送或执行失败才显示错误；明确未发送时可用“发送草稿”重试。任务是否执行完毕仍以会话内容和运行状态为准。

## 图片查看与缩放

点击图片后，在查看器内双指缩放、拖动、双击，或使用滚轮和底部缩放按钮查看细节。缩放范围为适应窗口的 100%–600%，点击百分比可复位；关闭后聊天页保持原尺寸。页面禁用普通双指、双击及快捷键缩放，输入框保持至少 16 px，避免手机输入时触发页面自动放大。浏览器或操作系统强制的辅助功能缩放仍由设备控制。

## 配对与设备管理

在运行 Gateway 的电脑上执行 `npm run pair -- --open`，手机扫码后点击“连接电脑”。二维码五分钟内一次有效。正常刷新和重新打开网页会保留配对；需要解除时可在“我的 → 我的设备”中解除配对，或在电脑管理设备：

```bash
npm run devices
node --import ./scripts/env.mjs --import tsx src/server/cli.ts revoke <device-id>
```

撤销会阻止该设备继续发起请求并关闭连接，但不能收回已经下载的内容或密钥。对象存储链接只包含附件密文。v1 升级到 v2 需要重新扫码一次。

在“我的 → 我的设备”切换已配对电脑；同一电脑的多个聊天共用连接。解除配对会清除该电脑对应的本地内容。

## 会话与项目

“最近”按更新时间显示会话，“项目”按桌面项目归属分组。可展开项目、搜索标题或项目名称，并加载更早的会话与历史消息。

已在桌面加载的会话可以直接控制。没有桌面 owner 的会话先提供只读历史；可尝试“在电脑打开此会话”，等待桌面加载后再发送。新建入口使用桌面原生能力，可创建独立会话或选择现有本机项目。

新会话与已有会话复用同一个消息输入组件。项目目录在后台更新，可以先写首条消息；标题可留空，由桌面自动生成，也可展开“自定义标题（可选）”手动设置。模型默认沿用桌面配置，支持为首条消息选择模型和思考强度。受桌面创建接口限制，首条消息目前支持文字，附件、技能、插件和计划模式可在创建后使用。

长会话中的工具活动先显示摘要，点击“展开活动详情”再读取完整输出与文件变更，减少手机首次加载的流量。

## 发送、追加、中断与排队

空闲时输入消息并点击箭头发送。任务运行时，点击发送会把文字和已上传附件追加到当前任务（也可只发附件）；长按 650ms 会排到下一轮，松开不会再发送一次。移开手指可取消长按，键盘等价操作为 Alt+Enter。

运行时清空输入，发送按钮会变为暂停图标，点击后中断当前 turn。暂停图标对应中断操作，不是可原地恢复的挂起。

右上角菜单可查看、移除排队消息和查看操作记录。运行中追加支持附件；排队仅支持文字。技能与插件需等当前任务结束后随新一轮消息发送，不支持的操作会保留草稿。

## 模型、计划、技能与插件

点击模型名称，在同一个面板选择模型、推理强度与速度，再点击“应用到下一轮”。运行中的任务保留原设置。

“工具”菜单提供计划模式开关。启用后输入区显示“计划”标签，点击标签上的关闭按钮可恢复默认执行方式。

技能和插件面板支持搜索与多选，点击“添加到消息”后才应用选择；关闭面板会取消本次未确认的改动。选中的内容与本条草稿绑定，发送成功后清除，不会自动沿用到所有后续消息。

## 问题与审批

点击问题卡片上的“回答”，逐题选择或输入内容。可以返回修改，最后核对并提交全部回答；仅选择选项不会自动提交。收起面板会保留本页答案，刷新页面不承诺保留答题草稿。

计划卡片可以“批准并执行”，或“提出修改”后用共享输入框发送修改意见。前者进入执行模式，后者保留计划模式；计划变化或已处理时会拒绝过期操作。

命令和文件审批会展示相关命令、路径或 Diff。按卡片提供的选项允许或拒绝。尚未适配的交互需要回到桌面处理。

## 附件与富内容

输入框的加号用于选择图片和文件，也可直接粘贴剪贴板中的图片；运行中同样可添加附件。文件上传完成后仍需点击发送；手机上传保留原始内容，当前最多十个附件、单文件上限 256 MiB。

普通消息中的图片直接显示，工具查看的图片位于对应活动折叠内。音视频使用浏览器播放器，可播放、暂停和拖动进度；编码支持取决于浏览器。代码、公式和图表会在内容稳定后完成排版。

文件链接只允许访问已经在当前会话中发送的附件。文件已被移动或删除时，旧链接可能失效。

## 断线与更新

页面先显示持久化缓存，再与电脑确认更新；断线或电脑离线期间可以阅读缓存，控制在恢复同步后重新启用。附件优先读缓存，避免重复下载。手机关闭或断开不会停止桌面任务。

“结果待确认”表示请求可能已送达，但尚未得到确定结果；先查看桌面记录，不要直接重发。

网页有新版时会提示刷新。未提交文字、附件、答案或正在提交的操作会阻止意外刷新；完成或清空后再更新。
