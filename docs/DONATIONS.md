# 支持项目页面配置

入口位于“我的”页面下方，在设置之后单独成组，标注“微信赞赏 · 爱发电”。聊天、工作台不插入弹窗或支付提示。

页面采用手机优先布局：微信赞赏码在前，爱发电主页链接在后，最后简要说明用途。支持完全自愿，不改变账户额度或现有功能。赞助者鸣谢仍为后续计划，不生成虚构名单或付款成功状态。

编辑 `src/web/public/support.json`：

```json
{
  "wechat": {
    "recipient": "公开的赞赏码名称",
    "qr": "/support/wechat-reward.png",
    "previewCrop": { "x": 0.248, "y": 0.124, "size": 0.504 }
  },
  "platform": {
    "name": "爱发电",
    "creator": "公开的创作者昵称",
    "url": "https://afdian.com/a/your-name",
    "enabled": true
  }
}
```

两个渠道均可独立省略。赞赏码只允许使用同源图片；原图放在 `src/web/public/support/`，不经压缩、重绘或重新编码。可选的 `previewCrop` 用于聚焦方形原图中的扫码区域，x/y/size 是原图边长的比例，必须保留完整码点与留白；它只改变页面预览的可见区域。未设置时展示完整图片。

赞赏码直接使用图片展示，不设置点击放大、弹窗或下载按钮，不拦截图片的原生长按菜单。仅在触屏设备（无悬停、粗指针）上显示“长按图片保存，再在微信扫一扫中从相册选择”的提示；电脑端不显示操作提示。图片失败时提供重试并隐藏长按提示。

爱发电 `url` 必须是无用户名密码的绝对 HTTPS 地址，使用新窗口打开并设置 `noopener noreferrer`。`enabled: false` 时显示主页准备中。二维码、昵称和链接都是公开信息，不要把平台 API token、商户密钥或支付凭据放进配置。

Node 与 Cloudflare 共用同一组件和配置，重新构建发布后生效，浏览器以 `no-cache` 读取配置。更换赞赏码或平台只需调整公开配置与图片。实际支付留在微信或第三方平台完成；本站不收集支付信息，也不根据图片点击推断付款结果。
