# 功能支持范围

当前适配 Linux 桌面版本 `26.1029.61003`。下表描述可用功能及其限制，其他桌面版本需要单独适配。

| 功能       | 支持情况                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 实时会话   | 快照、增量、断线恢复；控制需能发现当前桌面 owner                         |
| 项目与历史 | 项目分组、搜索、分页；不支持项目重命名或移动                             |
| 任务控制   | 发送、中断、运行中追加和下一轮队列；队列多端并发编辑仍需完善             |
| 模型设置   | 模型、推理强度、标准/Fast 速度；运行中修改应用于下一轮                   |
| 计划模式   | 启用与取消计划模式，沿用桌面权限设置                                     |
| 技能与插件 | 选择本机已安装内容并随新一轮消息使用；不支持安装管理或全部专用 UI        |
| 用户问题   | 阻塞与异步问题、多题填写、自由输入、核对后统一提交                       |
| 审批       | 命令与文件变更审批；部分权限申请、MCP 表单和身份验证仍需在桌面完成       |
| Markdown   | 标题、表格、列表、引用、任务列表和链接；不执行消息内脚本                 |
| 公式与代码 | KaTeX、按语言加载的代码高亮与复制；未知语言保留原文                      |
| 图表       | Mermaid 与图像；其他交互图表协议尚未完整适配                             |
| 图片与文件 | 图片预览、原图打开、会话内文件链接；原文件需仍可读取                     |
| 音视频     | 浏览器播放器、Range、签名链接续期；格式取决于浏览器支持                  |
| 工具结果   | 活动折叠、命令输出、Diff；工具图片跟随原活动分组展开                     |
| 手机上传   | 最多十个附件、单文件 256 MiB；网关分块传输，可接入对象存储直传           |
| 新建会话   | 独立会话或现有本机项目；不支持 worktree、远端主机或云端任务              |
| P2P        | 实时事件与控制的 WebRTC 数据通道，失败回退 WebSocket；文件上传尚不走 P2P |
| 对象存储   | 可选 CDN 与存储适配器接口，不内置厂商实现                                |
| 主屏幕安装 | 提供安装清单和静态资源缓存；不支持离线控制与推送                         |

## 内容长度

实时窗口保留最近 500 条归一化记录，更早的历史按需读取。单条实时文本或工具详情超过 100,000 字符时显示预览，任务完成后可展开全文。JSONL 单条记录上限为 4 MiB，内嵌图片上限约 24 MiB 编码数据。

历史中的全部内嵌媒体、原生应用组件和专用卡片尚未完整重建。未知工具结果保留活动记录。

## 文件访问与缓存

本地文件需作为链接或结构化附件出现在当前会话中，不能通过任意路径读取电脑文件。外部 HTTPS 媒体由手机直接访问源站，仍受源站权限与防盗链限制。

接入私有存储适配器后，私有媒体通过五分钟有效的签名链接读取。撤销设备会立即阻止新的访问申请，但已签发链接可能持续有效到到期时间。

## 设置与草稿

会话文字、附件、技能和插件草稿在切换会话时保留；当前设备标签页刷新也可恢复。桌面确认消息交付后，未继续修改的草稿才会清除。答题面板的草稿仅保存在当前页面。

技能、插件和附件暂不能随运行中追加或排队发送，界面会保留选择并禁用不支持的操作。
