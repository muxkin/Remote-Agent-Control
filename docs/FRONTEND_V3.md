# 前端模块：消息、联系人、工作台、我的

前端继续使用 React、Vite 和 TypeScript。应用壳承载多个功能模块，复用已有输入框、消息渲染和设备通信；不为每个 Agent 创建另一套前端。

## 页面与导航

- **消息**：字符串 UID 账户登录后的单聊/群聊、流式回复、附件、历史搜索、未读与已读回执。通用 HTTP API 支持任意 Agent 接入；未提供 Dot、OpenClaw 专用连接器。
- **联系人**：统一展示 Agent 和真实个人账户，支持用户名添加、搜索、类型筛选及发起聊天。
- **工作台**：Codex 项目、会话与任务控制，包括发送、中断、追加、审批、队列、模型设置、新建与附件。新建继续复用 `ChatComposer`，标题可选。
- **我的**：服务端账户、个人资料、Agent 接入、已配对电脑和设置。账户注册登录与原有设备配对独立。
- **设置**：清理缓存与关于；缓存用量仅在清理缓存条目旁显示，不在聊天界面展示管理指标。

宽度大于 700px 时，全局导航常驻左侧，会话列表与聊天区并排，聊天区使用剩余空间。窄屏采用单栏：一级页面显示底部导航，进入对话或管理详情后隐藏，返回一级页面时恢复。配对页独立显示。

应用壳按浏览器可见区域分配高度；列表与聊天各自滚动，输入区独立占位。单一视口监听器合并处理窗口与软键盘变化，捏合缩放时不重排界面。消息跟随仅调整聊天区域，不滚动外层页面。短窗口压缩装饰空间以保留操作区。

## 复用边界

`src/web/main.tsx` 启动应用和 PWA；`shell/AppShell.tsx` 管理导航及模块生命周期；`CodexWorkspace.tsx` 保留 Codex 工作流。切换模块时工作台保持挂载，保留草稿、订阅、操作状态与设备连接。

`shell/modules.ts` 声明内置模块和工具入口；`shared/messaging.ts` 定义统一用户、会话、消息和 `MessagingClient` 合约，`client/messaging.ts` 提供 HTTP 实现。IM 会话由独立 UUID 定位，与 Codex 任务状态分开。新增 Agent 工具通过工作台接入，不增加一套底部标签。注册项随发行包提供，不加载任意远程插件代码。

`TranscriptMessages` 接收调用方提供的助手名称和头像。IM 复用 `ChatComposer`、`SendButton`、`RichMessage`、文件卡片、附件操作与图片预览，提供单聊/群聊、流式更新和停止；其联系人、身份及消息语义见 [即时消息说明](MESSAGING.md)。`AttachmentAccessContext` 为 IM 注入独立的会话成员授权读取器，工作台仍使用既有附件管线。

路由通过 `page`、`thread`、`host` 表示模块和电脑范围，IM 用 `conversation` 表示独立会话，避免切换电脑后使用旧会话链接操作另一台设备。配对秘密仅从 fragment 读取并立即移除。设备管理在“我的 → 我的设备”。

## 交互与恢复

- 计划卡片识别 `item/plan/requestImplementation`，支持批准执行或用共享输入框提出修改。适配版本的批准流程为带计划正文的后续 turn；后端校验当前计划、原 turn、指纹和操作 ID，拒绝过期请求。
- 图片粘贴复用 `ChatComposer` 和已有加密上传管线。运行中可添加附件并追加，也可只发附件；队列仍仅接受文字，技能和插件留到下一轮。
- 回到前台或网络恢复后按同步位置确认订阅，瞬时失败重试，永久授权错误停止重试。有归属但未加载的桌面会话提供恢复入口，并等待实际运行状态加载。
- 未确认操作沿用原记录查询结果，不在重连时重新生成请求执行。

## 缓存

持久化缓存没有应用容量预算、配额比例、可配置上限或自动淘汰。空间由浏览器管理，写入失败不阻塞当前聊天或主动删除旧缓存。

缓存写入合并执行，清理与写入串行。清理保留身份、配对、草稿、未确认操作和上传续传记录；解除配对则清理对应数据。用量仅在进入设置时读取，不在正常聊天中持续统计。服务器有界增量日志和内存热缓存不属于手机持久化缓存预算。

## 验证与限制

2026-11-07 的统一视觉层由 `shell/surfaces.css` 管理，沿用主题语义颜色。消息与联系人复用 `DirectoryControls`（按需搜索、Esc 清除并收起、筛选）和 `DirectoryRow`（96 px 行、54 px 头像、名称与摘要、可选时间/未读/箭头），使用开放式细线列表。手机导航为保留安全区的悬浮底栏，桌面保持左侧导航；个人页和工作台采用同一间距、字重及图标规范。

`ConversationHeader` 由即时聊天与 Agent 工作台共用，手机统一 72 px 高度、40 px 操作按钮、17 px 标题和 12 px 副标题；长文本省略，状态与操作按钮不参与压缩。主题与业务状态仍由原组件维护。`Agent Space Display` 为 Noto Serif CJK SC Bold 的重命名字体子集，只含四个导航标题所需的 10 个汉字（6,384 字节），使用 `font-display: swap`，正文沿用系统字体；授权信息随发布包位于 `/fonts/agent-space-display-OFL.txt`。

`test:frontend` 验证模块、草稿、缓存清理和计划交互；`test:layout` 验证可见区域与恢复；`test:composer` 验证 320–1920px 布局、移动详情导航、剪贴板图片及运行中附件。均使用隔离模拟桌面，不向真实工作会话发送测试内容。

自动化可见区域与配额故障注入不能替代 Android/iOS 真机键盘、后台挂起和存储回收测试。当前验证范围见 [验证记录](VALIDATION_V2.md)，部署与回滚见 [部署指南](CLOUD_DEPLOYMENT.md)。
